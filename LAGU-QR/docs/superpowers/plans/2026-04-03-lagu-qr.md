# LAGU-QR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy a QR-code-accessible wedding programme image on S3 with a drag-and-drop upload page, all provisioned by a Crossplane XRD claim.

**Architecture:** A Crossplane `ImageHosting` XRD in diixtra-forge maps a simple claim to a Terraform Workspace that provisions S3 + Lambda + API Gateway + IAM. The claim lives in the LAGU-QR repo, reconciled by Flux via its own GitRepository source. The Terraform Workspace uses the existing Crossplane Terraform provider with AWS credentials passed as environment variables.

**Tech Stack:** Crossplane (XRD + Composition), Terraform (AWS provider via Crossplane Workspace), Python 3.12 (Lambda), Flux (GitOps), Kyverno Chainsaw (tests)

**Repos:**
- `diixtra-forge` — XRD, Composition, Terraform ProviderConfig, Flux source for LAGU-QR
- `LAGU-QR` — Claim YAML, QR generation script, docs

```yaml
# Terraform ProviderConfig — Amazon Web Services
#
# Used by Crossplane Terraform Workspaces that provision AWS
# resources. Unlike the native AWS provider (which uses INI-format
# credentials + assume-role), Terraform Workspaces pass credentials
# as environment variables in each Workspace's env block.
#
# This ProviderConfig uses the default in-cluster backend.
# Terraform state is stored as Kubernetes Secrets in the
# crossplane-system namespace.
# ══════════════════════════════════════════════════════════════════
apiVersion: tf.upbound.io/v1beta1
kind: ProviderConfig
metadata:
  name: aws-default
  labels:
    app.kubernetes.io/part-of: crossplane
    app.kubernetes.io/component: aws-terraform
    app.kubernetes.io/managed-by: flux
spec:
  configuration: |
    terraform {
      backend "kubernetes" {
        secret_suffix = "aws-terraform"
        namespace     = "crossplane-system"
        in_cluster_config = true
      }
    }
```

```yaml
# ══════════════════════════════════════════════════════════════════
# XRD — ImageHosting
#
# Provisions a publicly-readable S3 object at a fixed key, with a
# Lambda-backed upload page for replacing the object. Designed for
# hosting a single image (e.g. a wedding programme) behind a stable
# QR-code URL.
#
# Claim interface:
#   spec.region    — AWS region (e.g. eu-west-2)
#   spec.objectKey — S3 object key (e.g. programme.jpeg)
#
# Status outputs:
#   status.viewURL   — public URL for the hosted object
#   status.uploadURL — URL for the upload page
# ══════════════════════════════════════════════════════════════════
apiVersion: apiextensions.crossplane.io/v1
kind: CompositeResourceDefinition
metadata:
  name: ximagehostings.platform.diixtra.com
  labels:
    app.kubernetes.io/part-of: crossplane
    app.kubernetes.io/managed-by: flux
spec:
  group: platform.diixtra.com
  names:
    kind: XImageHosting
    plural: ximagehostings
  claimNames:
    kind: ImageHosting
    plural: imagehostings
  versions:
    - name: v1alpha1
      served: true
      referenceable: true
      schema:
        openAPIV3Schema:
          type: object
          properties:
            spec:
              type: object
              properties:
                region:
                  type: string
                  description: AWS region for all resources
                objectKey:
                  type: string
                  description: S3 object key for the hosted image
              required:
                - region
                - objectKey
            status:
              type: object
              properties:
                viewURL:
                  type: string
                  description: Public URL for the hosted image
                uploadURL:
                  type: string
                  description: URL for the upload page
```

```yaml
# ══════════════════════════════════════════════════════════════════
# Composition — ImageHosting
#
# Maps an ImageHosting claim to a Terraform Workspace that
# provisions:
#   - S3 bucket (public GetObject on the specified key)
#   - Lambda function (upload page + pre-signed URL generator)
#   - API Gateway HTTP API (fronts the Lambda)
#   - IAM role + policies (Lambda → S3, CloudWatch Logs)
#
# Uses the Terraform provider (not native AWS provider) because
# Lambda code deployment requires archive_file + inline source,
# which native Crossplane managed resources cannot express.
# ══════════════════════════════════════════════════════════════════
apiVersion: apiextensions.crossplane.io/v1
kind: Composition
metadata:
  name: image-hosting-terraform
  labels:
    app.kubernetes.io/part-of: crossplane
    app.kubernetes.io/managed-by: flux
spec:
  compositeTypeRef:
    apiVersion: platform.diixtra.com/v1alpha1
    kind: XImageHosting
  resources:
    - name: terraform-workspace
      base:
        apiVersion: tf.upbound.io/v1beta1
        kind: Workspace
        metadata:
          labels:
            app.kubernetes.io/part-of: crossplane
            app.kubernetes.io/managed-by: flux
        spec:
          deletionPolicy: Delete
          providerConfigRef:
            name: aws-default
          forProvider:
            source: Inline
            env:
              - name: AWS_ACCESS_KEY_ID
                secretKeyRef:
                  namespace: crossplane-system
                  name: aws-terraform-creds
                  key: aws_access_key_id
              - name: AWS_SECRET_ACCESS_KEY
                secretKeyRef:
                  namespace: crossplane-system
                  name: aws-terraform-creds
                  key: aws_secret_access_key
            vars:
              - key: region
                value: ""
              - key: object_key
                value: ""
            module: |
              # ── Variables ─────────────────────────────────────────
              variable "region" {
                type = string
              }
              variable "object_key" {
                type = string
              }

              terraform {
                required_providers {
                  aws = {
                    source  = "hashicorp/aws"
                    version = "~> 5.0"
                  }
                  archive = {
                    source  = "hashicorp/archive"
                    version = "~> 2.0"
                  }
                }
              }

              provider "aws" {
                region = var.region
              }

              # ── S3 Bucket ────────────────────────────────────────
              resource "aws_s3_bucket" "programme" {
                bucket_prefix = "lagu-qr-"
                force_destroy = true
              }

              resource "aws_s3_bucket_public_access_block" "programme" {
                bucket                  = aws_s3_bucket.programme.id
                block_public_acls       = false
                block_public_policy     = false
                ignore_public_acls      = false
                restrict_public_buckets = false
              }

              resource "aws_s3_bucket_policy" "programme" {
                bucket = aws_s3_bucket.programme.id
                policy = jsonencode({
                  Version = "2012-10-17"
                  Statement = [{
                    Sid       = "PublicReadObject"
                    Effect    = "Allow"
                    Principal = "*"
                    Action    = "s3:GetObject"
                    Resource  = "$${aws_s3_bucket.programme.arn}/$${var.object_key}"
                  }]
                })
                depends_on = [aws_s3_bucket_public_access_block.programme]
              }

              # ── IAM ──────────────────────────────────────────────
              resource "aws_iam_role" "lambda" {
                name = "$${aws_s3_bucket.programme.id}-lambda"
                assume_role_policy = jsonencode({
                  Version = "2012-10-17"
                  Statement = [{
                    Action    = "sts:AssumeRole"
                    Effect    = "Allow"
                    Principal = { Service = "lambda.amazonaws.com" }
                  }]
                })
              }

              resource "aws_iam_role_policy" "lambda_s3" {
                name = "s3-access"
                role = aws_iam_role.lambda.id
                policy = jsonencode({
                  Version = "2012-10-17"
                  Statement = [{
                    Effect   = "Allow"
                    Action   = ["s3:PutObject", "s3:GetObject"]
                    Resource = "$${aws_s3_bucket.programme.arn}/*"
                  }]
                })
              }

              resource "aws_iam_role_policy_attachment" "lambda_basic" {
                role       = aws_iam_role.lambda.name
                policy_arn = "arn:aws:iam::aws:policy/service-role/AWSLambdaBasicExecutionRole"
              }

              # ── Lambda ───────────────────────────────────────────
              data "archive_file" "lambda" {
                type        = "zip"
                output_path = "$${path.module}/lambda.zip"
                source {
                  content  = <<-PYTHON
              import json
              import boto3
              import os

              s3 = boto3.client('s3')
              BUCKET = os.environ['BUCKET_NAME']
              OBJECT_KEY = os.environ['OBJECT_KEY']
              BUCKET_REGION = os.environ['BUCKET_REGION']

              UPLOAD_HTML = '''<!DOCTYPE html>
              <html><head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1">
              <title>Upload Programme</title>
              <style>
              *{margin:0;padding:0;box-sizing:border-box}
              body{font-family:-apple-system,system-ui,sans-serif;background:#fef6f7;color:#333;display:flex;align-items:center;justify-content:center;min-height:100vh;padding:1rem}
              .container{max-width:400px;width:100%;text-align:center}
              h1{font-size:1.5rem;margin-bottom:.5rem;color:#c4747e}
              .drop{border:2px dashed #e8b4b8;border-radius:12px;padding:3rem 1.5rem;margin:1.5rem 0;cursor:pointer;transition:all .2s;background:#fff}
              .drop:hover,.drop.dragover{border-color:#c4747e;background:#fef0f2}
              .drop p{color:#888}
              .status{margin-top:1rem;padding:.75rem;border-radius:8px;display:none}
              .status.success{display:block;background:#e8f5e9;color:#2e7d32}
              .status.error{display:block;background:#fce4ec;color:#c62828}
              .status.uploading{display:block;background:#fff3e0;color:#e65100}
              input[type=file]{display:none}
              </style></head>
              <body><div class="container">
              <h1>Wedding Programme</h1>
              <p>Drop a new programme image to update</p>
              <div class="drop" id="drop" onclick="document.getElementById('file').click()">
              <p>Drop image here or click to browse</p>
              </div>
              <input type="file" id="file" accept="image/*">
              <div class="status" id="status"></div>
              </div>
              <script>
              const drop=document.getElementById('drop'),file=document.getElementById('file'),status=document.getElementById('status');
              function show(msg,cls){status.textContent=msg;status.className='status '+cls;}
              async function upload(f){
                show('Uploading...','uploading');
                try{
                  const r=await fetch('/presign');
                  const d=await r.json();
                  await fetch(d.url,{method:'PUT',body:f,headers:{'Content-Type':f.type}});
                  show('Programme updated!','success');
                }catch(e){show('Upload failed: '+e.message,'error');}
              }
              drop.addEventListener('dragover',e=>{e.preventDefault();drop.classList.add('dragover');});
              drop.addEventListener('dragleave',()=>drop.classList.remove('dragover'));
              drop.addEventListener('drop',e=>{e.preventDefault();drop.classList.remove('dragover');if(e.dataTransfer.files[0])upload(e.dataTransfer.files[0]);});
              file.addEventListener('change',()=>{if(file.files[0])upload(file.files[0]);});
              </script></body></html>'''


              def handler(event, context):
                  path = event.get('rawPath', '/')

                  if path == '/presign':
                      url = s3.generate_presigned_url(
                          'put_object',
                          Params={
                              'Bucket': BUCKET,
                              'Key': OBJECT_KEY,
                              'ContentType': 'image/jpeg',
                          },
                          ExpiresIn=300,
                      )
                      return {
                          'statusCode': 200,
                          'headers': {'Content-Type': 'application/json', 'Access-Control-Allow-Origin': '*'},
                          'body': json.dumps({'url': url, 'key': OBJECT_KEY}),
                      }

                  return {
                      'statusCode': 200,
                      'headers': {'Content-Type': 'text/html'},
                      'body': UPLOAD_HTML,
                  }
              PYTHON
                  filename = "index.py"
                }
              }

              resource "aws_lambda_function" "upload" {
                function_name    = "$${aws_s3_bucket.programme.id}-upload"
                role             = aws_iam_role.lambda.arn
                handler          = "index.handler"
                runtime          = "python3.12"
                timeout          = 30
                filename         = data.archive_file.lambda.output_path
                source_code_hash = data.archive_file.lambda.output_base64sha256

                environment {
                  variables = {
                    BUCKET_NAME   = aws_s3_bucket.programme.id
                    OBJECT_KEY    = var.object_key
                    BUCKET_REGION = var.region
                  }
                }
              }

              # ── API Gateway ──────────────────────────────────────
              resource "aws_apigatewayv2_api" "upload" {
                name          = "$${aws_s3_bucket.programme.id}-upload"
                protocol_type = "HTTP"
              }

              resource "aws_apigatewayv2_integration" "lambda" {
                api_id                 = aws_apigatewayv2_api.upload.id
                integration_type       = "AWS_PROXY"
                integration_uri        = aws_lambda_function.upload.invoke_arn
                payload_format_version = "2.0"
              }

              resource "aws_apigatewayv2_route" "default" {
                api_id    = aws_apigatewayv2_api.upload.id
                route_key = "$default"
                target    = "integrations/$${aws_apigatewayv2_integration.lambda.id}"
              }

              resource "aws_apigatewayv2_stage" "default" {
                api_id      = aws_apigatewayv2_api.upload.id
                name        = "$default"
                auto_deploy = true
              }

              resource "aws_lambda_permission" "apigw" {
                statement_id  = "AllowAPIGatewayInvoke"
                action        = "lambda:InvokeFunction"
                function_name = aws_lambda_function.upload.function_name
                principal     = "apigateway.amazonaws.com"
                source_arn    = "$${aws_apigatewayv2_api.upload.execution_arn}/*/*"
              }

              # ── Outputs ──────────────────────────────────────────
              output "view_url" {
                value = "https://$${aws_s3_bucket.programme.bucket_regional_domain_name}/$${var.object_key}"
              }

              output "upload_url" {
                value = aws_apigatewayv2_stage.default.invoke_url
              }

              output "bucket_name" {
                value = aws_s3_bucket.programme.id
              }
      patches:
        - type: FromCompositeFieldPath
          fromFieldPath: spec.region
          toFieldPath: spec.forProvider.vars[0].value
        - type: FromCompositeFieldPath
          fromFieldPath: spec.objectKey
          toFieldPath: spec.forProvider.vars[1].value
        - type: ToCompositeFieldPath
```

## Task 7: QR code generation script

**Files:**
- Create: `LAGU-QR/scripts/generate-qr.py`

- [ ] **Step 1: Create the QR generation script**

Create `scripts/generate-qr.py`:

```python
#!/usr/bin/env python3
"""Generate a QR code pointing to the wedding programme image.

Usage:
    python scripts/generate-qr.py <s3-view-url> [output-file]

Example:
    python scripts/generate-qr.py \
        "https://lagu-qr-abc123.s3.eu-west-2.amazonaws.com/programme.jpeg" \
        wedding-qr.png

Requires: pip install qrcode[pil]
"""

import sys

try:
    import qrcode
except ImportError:
    print("Install qrcode: pip install qrcode[pil]", file=sys.stderr)
    sys.exit(1)


def main():
    if len(sys.argv) < 2:
        print(f"Usage: {sys.argv[0]} <url> [output-file]", file=sys.stderr)
        sys.exit(1)

    url = sys.argv[1]
    output = sys.argv[2] if len(sys.argv) > 2 else "wedding-qr.png"

    qr = qrcode.QRCode(version=1, error_correction=qrcode.constants.ERROR_CORRECT_H, box_size=10, border=4)
    qr.add_data(url)
    qr.make(fit=True)

    img = qr.make_image(fill_color="black", back_color="white")
    img.save(output)
    print(f"QR code saved to {output}")
    print(f"Points to: {url}")


if __name__ == "__main__":
    main()
```
